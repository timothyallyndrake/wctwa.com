# Spacing tokens

Working direction, grilled 2026-10-14. One 4px scale for the whole marketing site.

| Token | Value |
|---|---|
| `space-1` | 4px |
| `space-2` | 8px |
| `space-3` | 12px |
| `space-4` | 16px |
| `space-5` | 24px |
| `space-6` | 32px |
| `space-7` | 48px |
| `space-8` | 64px |

Trust sections — photography, credentials, testimonials — use `space-6` through `space-8`.

Schedules and program details use `space-1` through `space-4`. Use `space-5` between groups.

Page content max width is `72rem`, from the layout direction.
