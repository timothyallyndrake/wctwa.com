# wctwa.com

Continue the marketing site from `docs/NOW.md`. Read it before editing pages, layout, or copy.

Reach the file that owns the fact:

- Where the work is, and what to do next: `docs/NOW.md`
- Which file owns which fact: `docs/README.md`
- Page shell, homepage regions, title band, header, footer: `design/layout.md`
- Color, type, spacing, shape: `design/tokens/`
- A locked product or technical choice, or a rejection: `docs/DECISIONS.md`
- What the legacy public site contains: `docs/CURRENT_SITE_INVENTORY.md`

When a change moves the phase, locks a choice, or changes page structure, update the file that owns that fact in the same change.
